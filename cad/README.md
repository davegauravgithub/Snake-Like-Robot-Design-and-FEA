# Original CAD files

The supplied `Snake Like Bot Files.rar` contains the following CAD source formats. Extract the archive locally and place the files here before pushing to GitHub.

- Creo/Pro-ENGINEER `.prt.1` parts: `base`, `fixedarm`, `head`, `ppropulsionarm`, `servo`, `snake`, `tail`, `wheel`.
- IGES `.igs` assemblies and individual parts, including `snake_assembly_15feb2020.igs`, `SNAKE_IGS.igs`, and seven `snake_assembly_17feb2020_part_*.igs` files.

The source archive was inspected but its compressed CAD contents could not be extracted in this environment, so they are **not included** in this starter package. Do not claim this repository contains CAD files until you add them.
